# Public Data Source Options

These Kaggle datasets are suitable starting points. Kaggle downloads usually require a Kaggle account and API token, so this project includes small sample data for the first prototype.

| Dataset | Why It Fits | Link |
| --- | --- | --- |
| CRM Sales Opportunities by innocentmfa | Fictional CRM opportunities with sales activities, deal stages, probabilities, and performance metrics. | https://www.kaggle.com/datasets/innocentmfa/crm-sales-opportunities/data |
| CRM Sales Opportunities by iamlynn | MavenTech-style CRM opportunity records with product, account, and won/lost outcome data. | https://www.kaggle.com/datasets/iamlynn/crm-sales-opportunities |
| Ecommerce Customer Behavior Dataset by Dhairyajeet Singh | Customer engagement, behavioral, transactional, and churn fields useful for conversion and prioritization modeling. | https://www.kaggle.com/datasets/dhairyajeetsingh/ecommerce-customer-behavior-dataset |
| Synthetic E-Commerce Customer Behavior Dataset by Lorenzo Scaturchio | Relational customer, transaction, session, and review tables for segmentation, conversion, and sentiment scenarios. | https://www.kaggle.com/datasets/lorenzoscaturchio/ecommerce-behavior |

Recommended first dataset: CRM Sales Opportunities, because it most closely matches the B2B sales pipeline scenario.
