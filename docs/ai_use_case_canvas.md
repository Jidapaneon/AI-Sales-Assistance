# AI Use Case Canvas

| Section | Content |
| --- | --- |
| Problem | Sales reps spend too much time summarizing meetings, writing follow-ups, and cleaning CRM notes. Managers lack reliable visibility into opportunity health. |
| Users | Sales reps, sales managers, sales operations, revenue leadership. |
| AI Solution | AI sales copilot that summarizes meetings, scores leads, drafts follow-up emails, flags opportunity risk, and standardizes CRM notes. |
| Data Inputs | CRM opportunities, account metadata, sales activity history, email engagement, meeting transcripts, notes, deal stage, deal value. |
| Output | Priority score, meeting summary, recommended next action, follow-up email draft, cleaned CRM note, opportunity risk flag. |
| KPI | Conversion rate, response time, admin hours saved, stale opportunity count, AI usage rate, pipeline coverage. |
| Business Value | More time for selling, better prioritization, faster follow-up, more consistent manager coaching, improved forecast confidence. |
| Risks | Hallucinated summaries, biased lead scoring, poor data quality, over-reliance on AI recommendations, sensitive customer data exposure. |
| Controls | Human approval before customer-facing messages, confidence labels, CRM source links, PII handling rules, prompt templates, audit logs. |
| Pilot Scope | One sales team, one quarter of opportunities, weekly manager review, compare AI-assisted results to baseline. |
